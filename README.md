# 🌬 AERIS v5.0 — Breathing Training Platform

**Breathe Better. Live Better.**

AERIS is an open-source Android breathing practices platform with AI-powered recommendations, health-grade safety features, and offline-first design.

## ⚠️ Medical Disclaimer

AERIS is NOT a medical device. Consult a healthcare provider before use.

## Features (v5.0 MVP)

- 8 science-based breathing protocols
- AI Engine: NSI (Nervous System Index) + BCI (Breath Capacity Index)
- Animated breathing guide with haptic feedback
- Safety system with contraindications filtering
- Progression & gamification (levels, streaks, badges)
- Dark theme optimized for relaxation
- EN/RU localization

# AERIS — Safety Documentation

## Medical Disclaimer

AERIS is NOT a medical device. This application is intended for general wellness purposes only and should not be used as a substitute for professional medical advice, diagnosis, or treatment.

## Contraindications

The following conditions require medical consultation before using advanced protocols:
- Hypertension (high blood pressure)
- Pregnancy
- Cardiac issues (arrhythmia, heart disease)
- Respiratory conditions (severe asthma, COPD)
- Psychological conditions (panic disorder, PTSD)

## Safety Rules

1. **Level-based blocking**: Protocols with minLevel > user level are blocked
2. **Contraindication blocking**: Protocols with matching contraindications are blocked
3. **Hypoxic adaptation**: Requires level 3+ (prevents beginners from dangerous breath holds)
4. **Consent**: Advanced protocols (Kumbhaka, Sitali) require explicit health consent
5. **Emergency stop**: Red STOP button always visible during sessions
6. **Skip hold**: Available during HOLD phases; 3 consecutive skips triggers recommendation for easier protocol
7. **HR threshold**: If user HR > 100 BPM, all hold durations are reduced by 50%

## Emergency Protocol

"Calm in 60 seconds" — 4s inhale + 6s exhale, no holds. Designed for acute stress moments.
